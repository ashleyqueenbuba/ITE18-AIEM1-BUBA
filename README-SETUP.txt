ASHLEY QUEEN BUBA — NUxt PERSONAL PROFILE WEBSITE
=================================================

PROJECT CONTENTS
----------------
app/
  assets/css/main.css       Tailwind CSS import + custom mauve/lavender styling
  components/
    ContourBackground.vue   Reusable contour-line background
  layouts/
    default.vue             Shared header, navigation, and footer
  pages/
    index.vue               Homepage
    profile.vue             Personal profile page
  app.vue                   Nuxt app entry
public/
  profile-picture.svg       Temporary portrait placeholder
nuxt.config.ts               Nuxt + Tailwind Vite configuration
package.json                 Project scripts and dependencies

REQUIREMENTS
------------
- Install Node.js (LTS version) from https://nodejs.org/
- Use a terminal such as VS Code Terminal, PowerShell, or Command Prompt.
- Internet is needed the first time to install dependencies and load Google Fonts.
